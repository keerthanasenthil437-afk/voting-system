# 🗳️ Online Voting System

## 📌 Description

A simple voting system built using PHP and MySQL.

## 🚀 Features

* Voter login
* Vote once restriction
* Candidate selection
* Result calculation with percentage

## 🛠️ Tech Stack

* PHP
* MySQL
* HTML
* CSS

## ▶️ How to Run

1. Install XAMPP
2. Place project in htdocs
3. Create database `voting_system`
4. Import SQL
5. Run `http://localhost/voting-system`
